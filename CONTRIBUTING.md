# How we work together

1. One idea in every commit. A recipe page and its link on the homepage are two commits.
2. A commit message finishes the sentence: "If I apply this commit, it will ..."
   Good: "Add pancake recipe". Bad: "stuff", "fix", "asdf".
3. Never commit to `main` directly in the team phase. Work on your own branch,
   named with your name, for example `anna-pancakes`.
4. Run `git status` before every commit, and read it.
5. Be kind in reviews: one nice thing, one question.
